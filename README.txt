# Naruto Senki — Rieyu Xhen (Toneri Tenseigan Edition)

## Pembaruan Tema Toneri Otsutsuki
- Palet warna diubah menjadi **Tenseigan Chakra Mode** (Cyan/Turquoise `#12ebd4`, Gudodama Emerald `#74ff9e`, Otsutsuki Gold `#e5c36b`, dan Deep Lunar Space `#050b12`).
- Gambar landscape Toneri (`1000003799.jpg`) disimpan sebagai `assets/toneri-banner.jpg` dan dipasang pada background utama Hero serta cover kartu mod pertama.
- Gambar portrait Toneri (`1000003769.jpg`) disimpan sebagai `assets/toneri-portrait.jpg` dan ditampilkan pada bingkai karakter Hero, bagian About, serta cover kartu mod kedua.

## Menjalankan di Android / Acode
1. Ekstrak `NarutoSenkiWeb.zip` ke folder di HP.
2. Buka folder `NarutoSenkiWeb` di Acode.
3. Buka `index.html` lalu gunakan Preview / buka di browser.
4. Edit `script.js` untuk mengubah data mod dan tautan download.
5. Edit `style.css` untuk menyesuaikan warna atau tata letak.

## Menambahkan tautan download
Di `script.js`, isi `downloadUrl` dengan tautan file yang benar-benar tersedia, misalnya direct download URL dari hosting yang Anda gunakan. Jangan biarkan tautan contoh/palsu.

## Mengganti cover mod
Di setiap objek mod pada `script.js`, isi `image` dengan path relatif seperti `assets/toneri-banner.jpg` atau `assets/toneri-portrait.jpg`. Simpan gambar tambahan di folder `assets`.
